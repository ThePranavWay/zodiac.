# Update — 21 October 2026 (upload + delete instructions)

## What changed
1. **Level files deleted** (see LEVELS.md): `public/attacks.html`,
   `public/investigate.html`, `public/next.html`, `public/later.html`,
   `public/level-session.js`.
2. **Launch page (`/`)**: much larger responsive THE ZODIAC SEEKER title in Cinzel, filling the full screen,
   full-screen hero, removed the "Four levels. One investigation. …" line,
   added a glowing orange **VIEW BROCHURE** button → `/zodiac-seeker-brochure.pdf`.
3. **Play page (`/play`)**: three new sidebar tabs before Case overview —
   **Mission Briefing**, **Objectives**, **Initial Evidence** (with the archived
   Reddit-post image and a Download Image button). Case overview, Field
   notebook and Leaderboard are kept (now tabs 04–06). New file `public/mission.css`.
4. Registration fixes: closed state is labelled on the register button,
   form errors scroll into view, and post-registration tab routing is
   guarded against stale cached scripts.
5. New assets: `public/zodiac-seeker-brochure.pdf`,
   `public/initial-evidence-reddit-post.png`,
   `public/theme-fonts/cinzel-700-900.woff2` (+ license).
6. Login cookie fix: correct-credential logins could appear to fail with
   "Please log in to your investigator account." when the site was opened
   inside a cross-site iframe (e.g. a hosted preview), because browsers
   reject `SameSite=Lax` session cookies there. The cookie mode is now
   configurable via `SESSION_COOKIE_SAMESITE` (default `Lax`, unchanged for
   normal top-level browsing; set `None` only for trusted iframe embedding —
   it forces `Secure`). Leave it unset on Vercel for the public site.
   Login/token forms also keep typed credentials if the follow-up session
   check fails.

No database or environment-variable change. Schedule: launch changed to
1 Nov 2026 12:00 AM IST per the organizer; close stays 13 Nov 2026 12:00 PM IST.

## Upload with GitHub (browser only)
1. Back up your current repository (Code → Download ZIP).
2. Extract the update ZIP and open the extracted folder. Inside it you should see `app.py`,
   `vercel.json` and the `public` folder together.
3. Open your website repository on GitHub **at its root** → Add file →
   Upload files → drag the **contents** of the extracted folder (not the ZIP,
   and no extra outer folder). Commit.
4. **Then delete these 5 files on GitHub one by one** (uploading never deletes):
   `public/attacks.html`, `public/investigate.html`, `public/next.html`,
   `public/later.html`, `public/level-session.js`
   (open file → Delete file → Commit, repeat).
5. Let the connected Vercel project deploy, then hard-refresh and check:
   `/` (big title + glowing brochure button), `/play` (login → Mission
   Briefing / Objectives / Initial Evidence tabs), `/attacks` should be 404.

Keep the same Vercel variables: `DATABASE_URL`, `SIGNING_KEY`,
`ORGANIZER_PASSWORD` (and any `LEVEL_*_PASSWORD_SHA256` you already use).
Never commit real secrets. Do not reset the event/database for this update.
